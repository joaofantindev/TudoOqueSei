/ sobre

Um repositório,
não um blog.

Cada nota é curta de propósito: uma ideia, um exemplo de código e o que ficou de aprendizado. O objetivo não é escrever artigos — é criar um lugar para revisar rápido.

  • 01HTML de verdade. As notas são escritas como <article class="card"> no próprio index.html — sem banco, sem servidor e sem build.
  • 02Tags com cor. Cada assunto tem uma cor própria, definida no CSS, que tinge os cards, os filtros e o destaque da página.
  • 03Busca instantânea. Filtre por tag, título, explicação ou trecho de código.
  • 04Sem login. Não há conta nem rascunho: o site é 100% estático. Para adicionar uma nota, edite o HTML e faça commit.
